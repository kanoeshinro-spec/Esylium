# Esylium

Esylium soll sich zu einem langfristig wartbaren, KI-gestützten Fantasy-RPG-Webgame entwickeln. Ziel ist eine persistente und dynamische Welt, in der Spielende eigene Figuren erschaffen, gemeinsam Abenteuer erleben und die Welt beeinflussen. Die Regeln und verbindlichen Änderungen des Spielzustands sollen durch deterministische, validierte Systeme kontrolliert werden; KI soll kreative Inhalte und flexible Reaktionen unterstützen.

## Entwicklungsstatus

Dieses Repository enthält derzeit **keinen Spielprototyp und keinen ausführbaren Anwendungscode**. Die einzige vorgefundene Datei war eine kurze README-Notiz. Der Projektverantwortliche hat mitgeteilt, dass ein Prototyp in Google AI Studio existiert; dieser war bei der Bestandsaufnahme nicht im Repository enthalten und konnte daher nicht technisch untersucht werden.

Es sind hier keine Programmiersprache, Frameworks, Build- oder Testbefehle, Deployment-Konfiguration, persistente Speicherung oder Gemini-/Google-AI-Studio-Integration nachweisbar. Die nachfolgenden Entwicklungsziele sind Vorschläge und keine Beschreibung bereits vorhandener Systeme.

## Technologien

Noch nicht festgelegt. Eine Entscheidung sollte erst nach Prüfung und Import des bestehenden Prototyps getroffen werden. Es werden daher keine Laufzeit-, Framework- oder Paketmanager-Abhängigkeiten vorausgesetzt.

## Lokaler Start

Aktuell gibt es keine Anwendung, die lokal gestartet werden kann. Nach dem Import des Prototyps werden dessen tatsächliche Installations-, Start-, Build- und Testschritte hier dokumentiert.

## Google AI Studio

Google AI Studio wird laut Projektauftrag für einen bestehenden Prototyp verwendet. Es gibt im Repository aktuell keinen synchronisierten Prototyp und keine nachweisbare Google-AI-Studio- oder Gemini-Anbindung. Behandle den Import und die Synchronisierung deshalb als nächsten Bestandsaufnahme-Schritt. Änderungen aus AI Studio und GitHub sollten über getrennte Branches und überprüfte Pull Requests zusammengeführt werden; Details stehen in [docs/DEVELOPMENT_WORKFLOW.md](docs/DEVELOPMENT_WORKFLOW.md).
