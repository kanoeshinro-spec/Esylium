# Mögliche Integration mit Game: Creation

> **Unverbindliche Zukunftsoption:** Die hier beschriebenen Schnittstellen sind Ideen für eine spätere Prüfung. Es bestehen derzeit weder eine technische Abhängigkeit noch ein implementierter Datenaustausch. Es wird kein Code aus Game: Creation kopiert.

## Unterschiedliche Schwerpunkte

- **Esylium:** individuelle Rollenspielperspektive, Charaktere, Abenteuer und Multiplayer-Erkundung.
- **Game: Creation:** autonome gesellschaftliche Entwicklung und strategische Weltsimulation.

Eine mögliche spätere Zusammenarbeit sollte diese Verantwortlichkeiten getrennt halten. Esylium soll weiter funktionieren, auch wenn Game: Creation nicht verfügbar ist.

## Denkbare Schnittstellen

Nur falls beide Projekte später einen konkreten Integrationsbedarf haben, könnten versionierte, dokumentierte Datenverträge unter anderem Folgendes austauschen:

- **NPCs:** Identität und ausgewählte, für Esylium relevante Zustandsinformationen.
- **Ressourcen:** definierte Bestände oder Veränderungen mit klaren Einheiten und Herkunft.
- **Weltzeit:** explizite Zeitpunkte oder Fortschrittsintervalle.
- **Fraktionen:** öffentlich benötigte Zugehörigkeiten und Beziehungen.
- **Ereignisse:** nachvollziehbare, versionierte Ereignisse mit eindeutiger Quelle.

Diese Beispiele sind keine existierenden Modelle oder APIs. Zugriffsrechte, Datenhoheit, Fehlerbehandlung, Versionskompatibilität und Konfliktauflösung müssten vor jeder Umsetzung geklärt werden. Verbindliche Aktionen und Spielregeln blieben bei Esylium validiert und autoritativ.
