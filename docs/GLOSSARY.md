# Glossar

Begriffe sind vorläufig und können mit Erkenntnissen aus dem importierten Prototyp angepasst werden.

| Begriff | Bedeutung |
|---|---|
| **Esylium** | Das geplante Fantasy-RPG-Webgame und dieses Repository. |
| **Spielzustand** | Verbindliche Daten über Figuren, Welt und Spielverlauf. Im aktuellen Repository nicht implementiert. |
| **KI-Spielleitung** | Geplante KI-Unterstützung für kreative Abenteuerinhalte und Reaktionen, ohne ungeprüfte Regelautorität. |
| **Deterministische Regeln** | Nachvollziehbare Regelverarbeitung, bei gleichen Eingaben mit konsistentem Ergebnis. |
| **Persistenz** | Dauerhafte Speicherung und reproduzierbares Laden von Spielzuständen. |
| **NPC** | Nicht von Spielenden gesteuerte Figur (Non-Player Character). |
| **Weltzeit** | Geplante Zeitbasis für Ereignisse und Entwicklungen der Spielwelt. |
| **Game: Creation** | Separates Projekt für autonome gesellschaftliche Entwicklung und strategische Weltsimulation. |
| **Google AI Studio** | Laut Projektauftrag genutzte Entwicklungsumgebung des externen Prototyps; eine Repository-Integration ist nicht nachgewiesen. |
